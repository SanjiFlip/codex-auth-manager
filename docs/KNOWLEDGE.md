# 蒸馏工作台与记忆库

v0.5.0 预览版新增功能，独立实现；Windows 与 macOS 安装包均包含蒸馏工作台和记忆库。

## 使用前准备

- Windows / macOS 安装官方 Codex CLI，并使用 ChatGPT 账号登录。管理工具需启用文件凭据管理。
- 本机验证 CLI 为 0.154.0；需要支持 `exec --ignore-user-config --ignore-rules --ephemeral --json`。旧版本不支持时应升级 CLI，不回退到交互终端。
- 模型下拉框直接读取本机 `models_cache.json` 中可展示的模型；推理强度只列出该模型声明支持的值。默认选中本机 `config.toml` 的模型与强度（有效时），否则使用目录默认值。读取列表不会联网、启动 CLI 或弹出终端。
- 缓存只是本机最后一次获取的目录，不能证明账号此刻的在线权限。没有缓存时，先在 Codex 中加载模型列表，再点击「重新读取」。开始蒸馏前后端会再次校验组合，并显式传入 `--model` 与 `model_reasoning_effort`；不会继承自定义模型代理、MCP 或 hooks。

## 蒸馏流程

1. 打开「蒸馏工作台」，点击「读取本机会话」。仅列出当前启用项目中的未归档 Codex 会话，按项目名称、会话 ID 或最近 7 / 30 天筛选。项目使用 Codex 中的名称，不显示目录路径。
2. 点击会话，勾选具体用户或助手消息。可以跨会话、跨页选取；每页展示 24 条消息，可「全选」当前会话全部可选消息（包含其他分页），再次点击「取消全选」。也可「只看已选」。不再提供独立的「清空」按钮。工具输出、系统消息和分析通道不作为素材。
3. 选择 Skill、工作流、提示词、个人偏好或任务记忆，填写标题，选择本机模型和推理强度；项目分类与补充要求位于可展开设置中。
4. 点击「预览并开始蒸馏」，核对模型、推理强度、消息序号与发送范围，确认后使用当前账号调用官方模型。任务会消耗该账号额度。
5. 草稿生成后查看、编辑并保存到记忆库，也可直接导出 Markdown。生成结果需自行核实，来源引用帮助回看，但不是事实正确性的保证。

运行过程中可取消；单次最长 3 分钟。退出管理工具会取消正在运行的任务。蒸馏期间本工具禁止切换账号，但无法阻止其他程序更改登录状态。

## 记忆与 Skill 如何复用

- 每页最多 24 个知识条目，可按最近更新或标题排序；支持搜索、类型与状态组合筛选，无结果时可一键清除筛选。
- 所有类型都可按项目归类、搜索、编辑、删除和导出；个人偏好与任务记忆是两种独立类型。
- 记忆属于本机知识库，跨账号共用，不随当前账号切换而改变。
- Markdown 可作为下一次会话的附件或上下文。保存到这里不意味着 Codex 自动读取。
- Skill 导出为包含 `name` / `description` 的 `SKILL.md`，正文包含方法与适用边界；第一版不生成脚本包、不自动安装，不写入现有 Skills Hub 或 Codex 记忆目录。
- 删除条目不删除原始会话或已经导出的文件。编辑冲突会要求刷新，避免覆盖其他窗口的修改。

## 数据与运行边界

- 只按用户操作读取 CODEX_HOME 的本机项目与会话索引（`state_*.sqlite` 和必要的桌面项目设置）。仅接受 Codex 来源、未归档且属于启用项目的会话，之后才打开 `sessions` 中对应的 `.jsonl`。不会读取项目目录内的代码或数据，也不读取归档目录、已移除项目、ChatGPT 项目或子代理会话。
- 读取正文、缓存命中和开始蒸馏前都会复查归档 / 项目状态。缺少索引或无法确认状态时明确报错，不退回全盘会话扫描。旧版项目名称从 Codex 的本地项目配置读取。
- 按项目索引选取最近 300 个符合条件的会话；超过 32 MB 的会话跳过。单个会话展示最近 500 条正文，过长消息不可选择。
- 会话列表每页 50 个，正文每页 24 条。目录缓存 15 秒，点击「重新读取」立即重扫；正文缓存会核对文件变化，并限制为 6 个会话、400 万字符。重新打开会话发现已选正文变化时，会取消旧选择并提示重新审阅。
- 每次最多 10 个会话、每会话最近 500 条消息、共 60000 字符。全选范围为当前会话最近 500 条完整可选正文；超过总字符限制会明确报错，不截断后悄悄发送。
- 发送内容为选中的正文、标题、补充要求与应用提示词。尝试遮盖常见令牌字段，但不能保证识别所有敏感文本；发送前应检查选中内容。
- CLI 使用独立临时工作目录、只读沙箱和非交互模式，禁用 shell、MCP 用户配置、插件、记忆、hooks 等相关能力，不加载项目 AGENTS.md。CLI 的临时模式不保存本次会话正文。
- 使用现有 CODEX_HOME 中的当前文件登录，不复制或输出账号令牌；CLI 仍可能正常刷新自己的登录凭据。
- 知识库位于管理工具数据目录的 `knowledge/knowledge.enc`，通过 Electron safeStorage 使用 Windows DPAPI / macOS Keychain 保护整个内容，包括标题、正文和来源。解密失败时保留原文件并报错，不静默清空。
- 知识库保存生成结果与来源元数据，不复制原始会话正文。导出的 Markdown 为明文；请自行选择保存位置。当前账号凭据的加密迁移功能不包含知识库，知识跨设备复用通过 Markdown 导出。
- 知识库目前最多 1000 条，每条正文最多 80000 字符。

## 验证

```sh
npm run check
npm test
npx electron scripts/knowledge-smoke.js
```

集成检查使用临时账户库、合成会话和模型替身，覆盖真实主进程、IPC、系统加密、两个新页面、草稿、保存、导出、重载、取消及切换账号保护。另使用本机 CLI 和一段合成偏好完成联网调用检查，不发送真实历史会话。

归档变化处理：读取列表与蒸馏前会重新核对可用会话。列表加载后才归档的聊天在点击时自动移除，其已选消息一起取消，不读取归档正文；Windows 扩展路径先解析为同一个真实文件再比较。
